# Why this desk has no front end

The recurring work is reviewing evidence, comparing recorded requirements and keeping a follow-up history. A coding agent runs those jobs against your database and returns the results in chat.

The read-only weekly snapshot and supplier documents are HTML files. They can be opened or printed, but contain no forms or action buttons. A phone capture app, scanned-document extraction, private supplier upload links, live notifications and a shared signed-in screen are separate features. They belong in a custom version when the business needs them.

This base suits an internal reviewer who can work from structured exports and protected documents. It does not replace a live vendor intake channel by itself. The local database works without an internet connection. The coding agent and optional hosted database have their own connectivity requirements.

Every shared deployment needs named users, scoped access, protected evidence storage and tested recovery. The local database owner account is privileged. An HTML file is a snapshot and can contain private information, so store and share it deliberately.
