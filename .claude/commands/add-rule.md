# Add required coverage

Read CLAUDE.md. Start from current records.

```bash
npm run certificates -- add-rule --profile=<code> --coverage=<name> --currency=NZD --minimum=<amount> --actor=<person>
```

Read profiles and the source contract. Use --additional-insured=true or --waiver=true only when required. Thresholds are contractual, not invented law. Quote flags containing spaces.

Use --json when checking exact values. Never invent a source document, review, actor or command result.
