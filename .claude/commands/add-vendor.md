# Add supplier

Read CLAUDE.md. Start from current records.

```bash
npm run certificates -- add-vendor --code=<CODE> --name=<name> --owner=<person> --profile=<profile> --actor=<person>
```

Check vendors for duplicates. Record a stable code and legal name. Optional --region and --retention=YYYY-MM-DD record local operating choices.

Use --json when checking exact values. Never invent a source document, review, actor or command result.
